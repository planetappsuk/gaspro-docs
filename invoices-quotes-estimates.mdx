---
title: "Invoices, quotes and estimates"
description: "Create billing documents, add line items, and send them to your customers."
---

GasPro handles three billing documents:

- **Invoice** — a request for payment.
- **Quote** — a fixed price for work.
- **Estimate** — an approximate price for work.

They share the same editor and sending flow. The differences are the numbering,
the available statuses and how you use them.

## Create an invoice, quote or estimate

<Tabs>
  <Tab title="Mobile">
    1. Open the **Create** tab and choose **Invoice**, **Quote** or
       **Estimate**.
    2. Select the customer and job address.
    3. Check the **Number**, **Issued** and **Due** dates. The number and due
       date come from your form settings.
    4. Tap **Add new Item** to add line items.
    5. Add **Notes** and attach any images you want printed on the PDF.
    6. Tap **Save**.
  </Tab>

  <Tab title="Desktop">
    1. Open **Invoices**, **Quotes** or **Estimates** in the sidebar and select
       the create button, or use the dashboard quick action.
    2. Select or create the customer, then select or create the job address.
    3. Check the **Number**, **Issued Date** and **Due Date**.
    4. Select **Add Item** to add line items.
    5. Add **Notes** and any images to print on the PDF.
    6. Select **Save**.
  </Tab>
</Tabs>

## Line items

Each line item has:

| Field | Notes |
| --- | --- |
| Item Name | The main description, for example "Boiler service". |
| Description | Extra detail shown under the item. |
| Price | Unit price in pounds. |
| Quantity | Number of units. |
| Tax | No Tax, 5% VAT or 20% VAT. |
| CIS Deduction | Not Applicable, 20% CIS or 30% CIS. |

GasPro calculates the **Tax Amount** and **Total** for the line. The document
summary shows **Subtotal**, **Total Tax**, **CIS Deduction** and **Total**.

<Note>
  Saved line items can be reused. On desktop, search **Saved items** and add one
  to the document. On mobile, open the line item list, search for an existing
  item and choose **Add to Invoice** or **Edit for this Invoice**.
</Note>

## View, print and send

Open a document from its list to see the PDF and its details.

<Tabs>
  <Tab title="Mobile">
    Tap **Send** to email the document, or use the share button to send the PDF
    through another app. The status button at the top lets you change the
    document status, and **Activity** shows what has happened to it.
  </Tab>

  <Tab title="Desktop">
    Select **Send to Client** to email the document. Use the PDF controls to
    download or print it. **Activity** shows what has happened to the document.
  </Tab>
</Tabs>

The email composer lets you add **To** and **CC** recipients, edit the
**Subject** and **Message**, and add attachments. The PDF is included.

<Tip>
  Set default CC addresses for invoices, quotes and estimates in
  **Settings → Company**.
</Tip>

## Statuses

| Document | Statuses |
| --- | --- |
| Invoice | Draft, Pending, Paid, Unpaid, Overdue, Cancelled |
| Quote | Draft, Pending, Accepted, Declined |
| Estimate | Draft, Pending, Accepted, Declined |

Change the status from the document page. On desktop, open the document and use
the status control. On mobile, tap the status button at the top.

## Convert to an invoice

Open an accepted quote or estimate and choose **Convert to Invoice**. GasPro
creates an invoice from the same customer, job address and line items, so you do
not need to re-enter them.

## Duplicate a document

Use **Duplicate** to create a new invoice, quote or estimate with the same
customer, job address and line items. This is useful for repeat work or for
starting a quote from an old invoice.

## Delivery status

Each emailed document records its delivery status: **Sent**, **Delivered**,
**Opened**, **Clicked**, **Bounced** or **Not sent**. Check this before chasing
a customer for payment.

## Find a document

On mobile, open **Invoices**, **Quotes** or **Estimates** from the dashboard,
then use the status segments and the search bar. The create button on each page
starts a new document of that type.

On desktop, each type has its own page with search and filters for **Status**,
**Issued Date**, **Due Date** and **Engineer**.

<Warning>
  Deleting an invoice, quote or estimate is permanent. Download the PDF first if
  you may need a copy.
</Warning>
