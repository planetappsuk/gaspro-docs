---
title: "Importing data"
description: "Bring customers, job addresses and appliances into GasPro in bulk."
---

Instead of typing records one at a time, you can import them from your phone's
address book or from a CSV file.

<Tip>
  Always download the GasPro template first and keep its column headings
  unchanged. Do not add extra columns or rename existing ones.
</Tip>

## Import customers or job addresses

<Tabs>
  <Tab title="Mobile">
    1. Open **Dashboard → Import**.
    2. Choose **Import Customers** or **Import Job Addresses**.
    3. Choose **Import from Phonebook** or **Import from CSV**.
    4. For phonebook, search for contacts, tick the ones you want, then choose
       **Import selected** or **Import all contacts**.
    5. For CSV, download the template, fill it in, select the file and upload it.
  </Tab>

  <Tab title="Desktop">
    1. Open **Customers** or **Job Addresses** in the sidebar.
    2. Select **Import customers** or **Import job addresses**.
    3. Download the template and complete it.
    4. Upload the CSV file. Files can be up to 10 MB.
  </Tab>
</Tabs>

Imported records appear in the relevant list. Check a few after importing to
make sure the columns were read correctly.

### Customer and job address columns

The customer and job address template uses these columns, in order:

`name`, `email`, `mobile`, `home_phone`, `apt`, `street`, `city`, `postcode`,
`country`, `notes`, `company`, `next_inspection_date`, `reference`

The last column, `reference`, is the optional **Unique Reference** and is
imported for both customers and job addresses. The customer-only columns
(`notes`, `company` and `next_inspection_date`) are ignored when you import job
addresses.

## Import appliances

Appliance import is available in the mobile app.

1. Open **Dashboard → Import → Import Appliances**.
2. Download the template.
3. Add one appliance per row, using the same format as the template.
4. Select the CSV file and upload it.
5. Review the result. GasPro shows how many appliances were imported, how many
   were skipped and any errors.

<Note>
  Appliance import is marked as a beta feature. Check imported appliances before
  using them on a certificate.
</Note>

## If an import fails

Check the following:

- The file is a **CSV**, not an Excel workbook (`.xlsx`).
- The column headings match the template exactly, including `reference` if you
  use unique references.
- Dates use the format shown in the template.
- Required fields are filled in for every row.
- The file is under the size limit (10 MB on desktop for customers and job
  addresses).

If the file still fails, try importing a small batch first to find the row with
the problem.
